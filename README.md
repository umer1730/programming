# C++ Programming Practice

This repository contains C++ practice tasks focused on printing gaming characters and simple designs using console output.

### Tasks Covered
- Gun Designs
- Pacman
- Maze Patterns
- Food Characters
- Spacecraft Designs
- Other Gaming Characters and ASCII Art

### Concepts Practiced
- Basic C++ Syntax
- `cout` for Output
- Escape Sequences
- Console Printing

### Purpose
To practice basic C++ output statements and create simple gaming designs using text and symbols.
